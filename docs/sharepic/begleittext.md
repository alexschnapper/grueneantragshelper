## LinkedIn

Ein kleines Ehrenamtsprojekt zur BDK 2026: der Antragshelper.

Wer auf antraege.gruene.de einen Antrag einreichen will, braucht Mitantragsteller*innen – mit Gesamt- und Frauenquorum. Der Antragshelper zeigt auf einen Blick, wie viele noch fehlen, und bietet ein Dashboard mit Statistiken zu Anträgen und Änderungsanträgen.

Technisch: Python, serverseitig gerenderte Diagramme, statische Seite auf GitHub Pages. Eine stündliche Prüfung mit einem einzigen Abruf entscheidet, ob neu gebaut wird – jeder Abruf ist auf einer Transparenzseite einsehbar. Namen werden nicht gespeichert.
